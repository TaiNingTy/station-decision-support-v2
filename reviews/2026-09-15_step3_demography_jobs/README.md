## 实现要点与本步发现

- **几何一致**：人口层按空间连接包的参数重建环带并逐站核对面积（偏差 0），就业层直接消费人口层的陆地几何与分析目标，三层用同一套几何。
- **陆地几何**：2020 P.L. 街区擦除 2024 水域面要素；范围按 tract 取完整（39 tract、83 block group、844 街区，44 个街区被擦去水域），分母不裁切；擦除后与 `ALAND20` 属性最大偏差 0.16%。
- **份额与误差**：每站三环带份额之和与累计盘份额精确相等（偏差 0）；计数 MOE 按 RSS 合并并标明不含空间分摊的不确定性；比例用 Census 近似公式；收入中位数只做分组插值，不平均。
- **发现：B18101（残障）在 block group 级不发布**，API 返回全 null。改拉 tract 级，D13 与 R06 按 tract 陆地份额分摊，字段标 `geography_unit: tract`，契约 §3 已注明。获取脚本对其余十张表加了"block group 级有估计"的硬性检查。
- **重叠处理**：每站画像非排他；全网合计在并集上算一次。人口：去重 76,357 对相加 420,877；岗位（JT00）：去重 180,847 对相加 1,344,824。67,711 人住在被两站以上覆盖的区域。
- **LODES 对账**：候选街区上 WAC = OD(main) + OD(aux) 对 JT00 与 JT01 精确成立；RAC 比 OD(main) 居住端多 423 份，即居民在州外工作的岗位，属于已声明的缺口。
- **可复现**：两层无变化重跑均复用同一包 ID、逐字节一致；`od_links_subset.csv.gz` 把 gzip 时间戳置零以保证字节一致。
- **包 ID 变化**：依赖锁加入 pyshp 后，每个 manifest 里的环境记录不同，用编排器重发了三层的包；空间连接的分析产物与上一包逐文件比对，只有两个文件的 `environment.lock_sha256` 不同，其余六个逐字节相同。旧包目录保留。

[regression_results.json](regression_results.json)：19 个场景、180 项检查，全部在临时副本中运行，本目录只读。本步新增两个场景，21 项检查：

| 场景 | 验证内容 |
|---|---|
| `demography_jobs_layers` | 两层 DONE、校验 PASS、消费关系正确（人口层消费空间连接包，就业层消费人口层包）、WAC 与 OD 恒等式成立、全网去重不高于相加值、残障指标为 tract 级、两层的包与本目录已发布的包逐字节一致（独立副本从头重建，跨副本确定性） |
| `raw_change_layers_stale` | 只改一个 ACS 原始文件不重新获取：人口层 STALE 并点名该文件，就业层因上游未 DONE 而 STALE，AI 标志为 false；此时重建人口层会在原始文件哈希门禁处停止，指针不变 |

既有场景随编排器一起覆盖两层：无变化重跑全部数据文件逐字节一致；站点、窗口、zoning 变化的传递链；空间连接重发包后两层 STALE；注释级代码改动只提示不过期。
